# PDX Mod Hub

One dashboard for every Steam Workshop mod across your Paradox Interactive games.

PDX Mod Hub is a local web app: a small Node.js server scans your Steam libraries, tracks Workshop updates through the public Steam Web API, scrapes changelogs, and serves a modern single-page UI in your browser. Subscribing and downloading are delegated entirely to the Steam client itself through short-lived Steamworks helper processes — no credentials, no duplicate downloads.

Status: scaffolding.
