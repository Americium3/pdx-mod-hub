# API / Architecture Amendments (from adversarial review)

ALL blocker/major findings folded; the API contract below supersedes the draft.

DATA MODEL (per mod): { id, appId, acf: {present, acfTs, manifest, sizeOnDisk}|null, account: {subscribed, asOf}|unknown, remote: {fetchStatus: ok|removed|banned|private|error, remoteTs, lastOkAt, meta(title, previewUrl, sizeWorkshop, subs, favorites, votes, tags, children[], dlcRequired[]), never overwritten by non-ok responses}, lastSeenRemoteTs, latestAcf: {latestTimeupdated, latestManifest}, branchRange {min,max}|null (nullable from day one; Vic3/EU5 author_snapshots), source: workshop|local, dominantColor (cached). Per game: {appId, name, installed, hasWorkshopAcf, browsable (static table + cached probe), libraryPath, warnings[], syncedAt, libraryOffline}. games[] driven by appmanifest presence + static Paradox appid list, includes zero-mod games.

STATE DERIVATION (computed, never stored as events): update-unseen-by-steam = remoteTs > latestTimeupdated (hot state); update-pending-launch = latestTimeupdated ≥ remoteTs AND latestManifest ≠ installed manifest (calm state); downloaded/up-to-date from ACF; orphaned ONLY when installed && account.subscribed==false && account fresh (asOf < N hours or post-dates local actions); stale account ⇒ "unverified", never orphaned; not-installed = account.subscribed && !acf. Account set refreshed by piggybacking getSubscribedItems on EVERY helper launch (zero extra flashes); optimistic mutation on successful subscribe/unsubscribe.

EVENTS (blocker 1): add lastSeenRemoteTs distinct from acfTs. Emit ONE update event iff newRemoteTs > lastSeenRemoteTs AND lastSeenRemoteTs != null (first observation seeds silently, no first-run flood). Separate 'downloaded' event only on ACF per-item timeupdated/manifest transition from the watcher diff. Distinct 'mod_removed'/'mod_banned' events on fetchStatus transitions; suppress update events when the previous poll lacked a valid remoteTs (private→public flip). Every event snapshots {title, previewUrl} at creation so feed history survives removal. Events carry {seq (monotonic, persisted across restarts), modId, appId, type, ts (time_updated, sort key), detectedAt}. Retention: max(500, 90 days), compact on startup, dedupe on (modId,type,ts); NDJSON append-only if >1MB.

CHANGELOG (blocker 2): API = GET /api/mods/:id/changelog?before_ts=&limit=20 → {entries:[{ts, ord, html, fetchedAt}], hasMore, syncedThroughTs}. No ?page= ever. Steam ?p=N is fetch-side only: fetch p1 when remoteTs > newest cached ts, walk deeper until overlap with cache (hard cap 30 pages); overwrite same-ts entries on refetch (author edits); key (modId, ts, ordinalWithinTs). Error page detected by title/DOM marker ("Steam Community :: Error") → {status:'unavailable', checkedAt} TTL 6h, never cached as content. Empty prose = real entry (empty html). Expected-entry-missing ⇒ negative record TTL 15min, capped retries. ONE global fetch queue (single worker, 4s spacing, prefetch lower priority, prefetch set capped N≈20, per-modId in-flight dedup; user expand joins pending promise); 429 ⇒ exponential backoff on the queue; 8s hard timeout per request + per-host circuit breaker (steamcommunity is frequently blocked/slow from CN, degrade to "changelog unavailable" without stalling anything). Sanitize server-side BEFORE caching.

ACTIONS (blocker 3): all POST /api/actions/* (subscribe|unsubscribe|download|sync|syncAll) return 202 {actionId}; progress via SSE action events {actionId, stage: queued|helper_starting|subscribed|downloading|result|acf_confirmed|result_ok_unconfirmed|failed, detail, queuePosition}; GET /api/actions/:id for reconnect catch-up. Server holds ONE global action queue: a single helper child alive at any time across all appids, strictly serialized; busy ⇒ 202 queued. Pre-check steamRunning ⇒ typed 409 {error:'steam_not_running'}. Force-download success is TWO-PHASE: stage 'result' = DownloadItemResult filtered by BOTH appid AND publishedfileid; success = 'acf_confirmed' (fs.watch sees that item's timeupdated/manifest advance ≥ remoteTs); result-ok with no ACF change within 120s ⇒ 'result_ok_unconfirmed' with guidance. Mod state flips ONLY from the ACF diff (same path as organic downloads). Subscribe+download batched into a single helper invocation. Helper: spawn/execFile shell:false, args validated /^[0-9]+$/; hard timeout kill; PIDs tracked and tree-killed (taskkill /T /F) on server exit; init-failure ⇒ 'start Steam' error. Subscribe for a zero-mod game: immediately insert mod record {source:'action', account:{subscribed,asOf:now}, acf:null, remote: one-off GetPublishedFileDetails} rendered as not-installed; directory watcher catches appworkshop ACF creation and promotes it.

WATCHER: watch the steamapps/workshop DIRECTORY per reachable library (never the ACF file; rename replacement kills file watchers on Windows), filter filename prefix appworkshop_, debounce 2s trailing per appid, parse with retry (3×250ms, tolerate failure silently), diff against last snapshot per item; emit only on real timeupdated/manifest change (discard Steam's no-op rewrites); ACF deletion = diff to empty. Backstop: fs.stat mtime poll every 60s. Watch libraryfolders.vdf too; re-resolve on change.

MULTI-LIBRARY: authoritative appworkshop ACF = the one in the library whose steamapps/ contains appmanifest_<appid>.acf; ignore others; duplicated appmanifest ⇒ newest mtime + warning in games[].warnings. Per-library try/catch; unreachable drive ⇒ games marked library_offline, never removed (no false orphan walls). Battle-tested VDF parser with escape handling.

SSE: poke channel only; events {type: state|feed|action, seq}, id: = seq (Last-Event-ID works), heartbeat comment every 25s; on every 'open' client refetches /api/state + /api/feed?after_seq=<lastSeen>. /api/feed gains cursors: ?before_seq=&after_seq=&limit=50 (stable under head insertion; after_seq doubles as tab-closed catch-up). Bound connections, clean up on disconnect.

STATE PAYLOAD: /api/state = slim summaries only (id, appId, title, state, remoteTs, acfTs, previewUrl, sizes, subs, source, branchRange) + games[] + lastPoll{at,status} + steamRunning + helperActive + seq + etag; full description/tags/stats/deps move to GET /api/mods/:id (fetched on expand/detail).

BROWSE: POST /api/browse/:appId {q, sort, page} (POST, a helper-spawning endpoint must never be a cacheable/prefetchable GET). Sort enum {relevance(requires q→RankedByTextSearch), updated, published, trend7d, trend30d, popular}; server validates legal q/sort combos (400); response {items, page, perPage:50, total, capped:boolean}. Helper SESSION lifecycle: one child kept alive with 60s idle timeout / 10min hard cap; one in-game flash per browse session, not per page; helperActive exposed in /api/state. Results cross-referenced against account set + ACF server-side for subscribed/installed badges. POST /api/sync (all games) runs per-app syncs sequentially through the single helper queue with per-app SSE progress and independent syncedAt; per-app /api/sync/:appId kept.

POLLER: GetPublishedFileDetails chunked ~100 ids/request, mapped by publishedfileid (missing id in response = error, not removed); transport failure leaves all statuses untouched, sets lastPoll.status='failed' + backoff, UI shows staleness; 8s timeouts.

SECURITY POSTURE (all three blockers + rebinding): (1) Host-header allowlist on ALL routes: exactly 127.0.0.1:8768 / localhost:8768 (kills DNS-rebind reads); bind IPv4 127.0.0.1 only. (2) CSRF: Origin allowlist (http://127.0.0.1:8768, http://localhost:8768) on every non-GET route; express.json() as the ONLY parser with type:'application/json' (text/plain never parsed); custom header X-PMH: 1 required on all /api routes except /api/img and SSE (forces preflight; never enable CORS). (3) XSS: BBCode → strict whitelist converter (b,i,u,strike,br,p,ul,ol,li,a,img,code,pre,h1-h3,quote,spoiler) → DOMPurify server-side; changelog HTML sanitized at fetch time BEFORE caching; hrefs http(s) only (no javascript:/data:), rel=noopener target=_blank; [img] src rewritten through /api/img. CSP on the SPA: default-src 'self'; script-src 'self'; img-src 'self'; connect-src 'self'; frame-ancestors 'none'; object-src 'none'; plus X-Frame-Options DENY, X-Content-Type-Options nosniff, Referrer-Policy no-referrer. (4) /api/img SSRF hardening: https only; hostname allowlist {*.steamstatic.com, steamusercontent.com, steamuserimages-a.akamaihd.net}; resolve DNS, reject private/loopback/link-local, pin resolved IP for the connection; redirect:'manual' (follow ≤2 hops re-validating); response timeout + 10MB per-object cap; image/* content-type only; cache key sha256(url) hex; total cache 500MB LRU; size + Clear exposed in Settings. (5) Settings: PATCH semantics, whitelist keys, reject __proto__/constructor/prototype on merge; pollIntervalSec clamped [60,3600]; language enum; prefetch bounded; dataFolder must be absolute, existing, writable (temp-write probe), ≠ current; change = explicit migration (pause poller/watchers → copy → verify → atomic swap → resume) or 409 if an action is in flight; 422 with per-field errors; response echoes applied settings. Theme is NOT a server setting (localStorage only).

STORE & PROCESS: authoritative state in memory; per-file async write mutex serializing read-modify-write; unique temp names (pid+rand) in the SAME directory, fsync+rename, retry rename 5×100ms on EPERM/EBUSY; keep .bak, load falls back parse→.bak→fresh default with logging. EADDRINUSE ⇒ probe GET /api/ping identity; if an instance exists, open browser to it (single-instance lock); port configurable. All timestamps on the wire are unix epoch ints named *Ts, zero date strings.

Endpoint summary (final): GET /api/state · GET /api/mods/:id · GET /api/mods/:id/changelog?before_ts&limit · GET /api/feed?before_seq&after_seq&limit · POST /api/actions/{subscribe,unsubscribe,download} · POST /api/sync/:appId · POST /api/sync · POST /api/browse/:appId · GET /api/actions/:id · GET /api/events (SSE) · GET /api/img?u= · PATCH /api/settings · GET /api/ping.
