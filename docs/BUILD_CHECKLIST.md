# Build Checklist

PHASE 0 — FOUNDATIONS (security first; cheap now, impossible later)
1. Express skeleton on 127.0.0.1:8768 + middleware stack in order: Host allowlist → security headers (CSP/XFO/nosniff/Referrer-Policy) → Origin allowlist + X-PMH header on non-GET → express.json(type:'application/json') only. GET /api/ping identity + EADDRINUSE single-instance handling.
2. JSON store module: in-memory authority, per-file write mutex, same-dir temp + fsync + rename with EPERM retry, .bak recovery chain, prototype-pollution key rejection.
3. VDF/ACF parsing (battle-tested parser), library enumeration from libraryfolders.vdf, authoritative-ACF rule (appmanifest co-location), per-library try/catch + library_offline, games[] from appmanifest + static Paradox appid list (zero-mod games included).

PHASE 1 — DATA & EVENT ENGINE
4. Mod record model (acf/account/remote/lastSeenRemoteTs/latestAcf/branchRange/source) + state derivation incl. the update-unseen vs update-pending-launch split and account staleness rules.
5. Poller: chunked keyless GetPublishedFileDetails mapped by publishedfileid, fetchStatus handling (ok/removed/banned/private/error, last-known-good preserved), timeouts + backoff + lastPoll status.
6. Event engine: lastSeenRemoteTs diff, silent first-run seed, downloaded/removed/banned events, title+preview snapshots, seq counter, NDJSON-ready retention/compaction/dedupe.
7. Directory-level workshop watcher per library + 2s debounce + parse retry + per-item diff + 60s mtime backstop + libraryfolders watch.
8. SSE poke channel (seq ids, heartbeats) + /api/feed cursor API + /api/state slim + /api/mods/:id detail split.
9. Local-mod scan (Documents/Paradox Interactive/<game>/mod) → source badge data [mustHave: source badge per mod].

PHASE 2 — EXTERNAL SURFACES

## Must-fix before v1

1. Update events must diff against lastSeenRemoteTs (persisted last-polled remote value), never against ACF timeupdated — with silent first-run seeding; ACF only feeds derived state and 'downloaded' events (BLOCKER)
2. Changelog API must be cursor-based (before_ts+limit) over the locally-ordered entry list keyed (modId, ts, ord); Steam ?p=N is fetch-side only with overlap-walk + 30-page cap + same-ts overwrite (BLOCKER)
3. All actions become async jobs: 202 + actionId, SSE progress stages, GET /api/actions/:id catch-up, ONE globally serialized helper process, typed 409 when Steam not running (BLOCKER)
4. CSRF defense: strict Origin allowlist on all non-GET routes + required X-PMH custom header + express.json as sole parser with type:'application/json' (text/plain never parsed) (BLOCKER)
5. Stored XSS: whitelist BBCode converter + DOMPurify sanitization server-side BEFORE caching for descriptions and changelogs; http(s)-only hrefs; [img] rewritten through /api/img; CSP + frame-ancestors none + nosniff + no-referrer (BLOCKER)
6. SSRF: /api/img restricted to https + Steam-host allowlist, DNS resolved/pinned with private-range rejection, manual redirects, 10MB object cap, 500MB LRU cache, sha256 filenames (BLOCKER)
7. Host-header allowlist (exactly 127.0.0.1:8768 / localhost:8768) on ALL routes to kill DNS-rebinding reads of /api/state (MAJOR)
8. Browse must be POST (no side-effectful GETs that spawn the helper) with validated sort-enum/q combos, capped pagination flag, and a helper SESSION (60s idle / 10min cap) so pagination costs one in-game flash, not N (MAJOR)
9. Helper process hygiene: shell:false spawn with /^[0-9]+$/ arg validation, hard timeouts, PID tracking + Windows tree-kill on exit, batched subscribe+download, init-failure surfaced as 'start Steam' (MAJOR)
10. Account-set state machine: orphaned/not-installed computed only from fresh sync data (getSubscribedItems piggybacked on every helper launch, optimistic mutations on actions); stale data renders 'unverified' + 'Sync to verify', never a false orphaned claim (MAJOR)
11. result=9/banned/private handling: per-mod fetchStatus, never overwrite last-known-good metadata, snapshot title+preview into every event, distinct mod_removed/mod_banned feed events, transport errors kept separate, responses mapped by publishedfileid (MAJOR)
12. Split the key state: update-unseen-by-steam (remoteTs > ACF latest_timeupdated — hot amber) vs update-pending-launch (Steam noticed, defers to game launch — calm amber), derived from latest_timeupdated/latest_manifest (MAJOR)
13. Force-download success = two-phase: DownloadItemResult filtered by appid+publishedfileid ('result') then ACF confirmation ('acf_confirmed'); mod state flips only from the ACF diff; 120s unconfirmed timeout with guidance (MAJOR)
14. fs.watch on the workshop DIRECTORY per library (never the ACF file), 2s debounce, parse-with-retry, per-item snapshot diff discarding no-op rewrites, 60s mtime backstop, handles missing/created/deleted ACFs (MAJOR)
15. Multi-library resolution: authoritative ACF = library containing appmanifest_<appid>.acf; offline drives mark games library_offline instead of producing false orphan/uninstall diffs (MAJOR)
16. SSE reconnect contract: poke-only events with persisted monotonic seq as SSE id, 25s heartbeats, client refetches state + /api/feed?after_seq on every open; /api/feed gets before_seq/after_seq/limit cursors (MAJOR)
17. Changelog scraper: detect the HTTP-200 'Steam Community :: Error' page, negative-cache unavailable/missing entries with TTLs, single global 4s-spaced queue shared by lazy+prefetch with in-flight dedup, 8s timeouts + per-host circuit breaker (owner is behind a CN network where steamcommunity stalls) (MAJOR)
18. Zero-mod-game subscribe landing path: immediate synthetic mod record + directory watcher catches ACF creation; games[] includes installed Paradox games with zero workshop items (MAJOR)
19. Settings: PATCH with per-field 422s, clamped poll interval [60,3600], enum language, whitelist keys + prototype-pollution rejection, data-folder change as explicit pause-copy-verify-swap migration or 409 mid-action (MAJOR)
20. JSON store: per-file async write mutex around read-modify-write, same-directory unique temp + fsync + rename with EPERM/EBUSY retries, .bak recovery on corrupt load (MAJOR)
21. Poller resilience: chunked (~100 id) keyless batches, timeouts, exponential backoff, last-known cache on failure with lastPoll.status surfaced as staleness in the ops bar (MAJOR)
22. Three-state theme (auto/dark/light) with the complete light palette implemented as data-theme-swapped CSS custom properties, pre-paint inline script, localStorage persistence, and light-mode image borders/dark scrims so Steam art never blows out (OWNER REQUIREMENT — v1 gate)

## Judge verdicts

- winner: GROUND STATION — Judged on specifics, not pitch prose. GROUND STATION wins on the two axes the owner explicitly named: no-AI-look and disciplined liveliness. Its palette is the only one that escapes the default dark-dashboard cast by construction — cool graphite #0A0C0E→#1D2328 with an explicit 'not zinc-blue' stance, one saturated accent (#FFB454) that doubles as the key PENDING state (brand = the product's reason to exist), and desaturated go-green #55C186 confined to dots/stamps. The all-Plex tri-voice system (Sans / Sans Condensed caps labels / Mono telemetry with tabular-nums and right-aligned numeric columns) is coherent, earned, and unmistakable for a template; condensed-caps-labels-as-grouping instead of boxes is a real density move. Its motion spec is the most rigorous of the three: three tokenized springs with sane values, the 4-beat ~700ms pending→fetched sequence as the app's only glow, pulses explicitly rationed (3 cycles then hold), no table entrance animation ever, and a complete reduced-motion downgrade path. Its weaknesses are honest ones: the mission-control metaphor is tonally cooler than CK3/EU4 painted art (mitigated by the rest-state desaturation and scrim discipline, hence contentFit 7), and the split-flap digits + spine sweep + brackets are the most bespoke build items (implementability 8, still fully realistic for one engineer — the 'split-flap' is really a translateY odometer roll). MARQUEE is a very close second: best content fit (built around Steam capsule art, poster cases, launcher familiarity) and equally strong motion (the continuous beacon edge narrative and press physics are excellent). But it fails the owner's #1 stated requirement hardest: hue-222 slate surfaces (#0A0C11/#10131A) are the single most common AI dark-theme cast, its state colors are near-verbatim Radix (#E5484D, #4CC38A), and 'Steam-adjacent familiarity' is pitched as a feature when the brief demands distinctiveness — Archivo Expanded and the beacon can't fully rescue a foundation this recognizable. GAZETTEER is the most thematically resonant with Paradox (dispatches/heraldry/plates rhyme with Vic3/EU4 beautifully) and the easiest to build, but two specifics sink it: Cormorant Garamond at 21px headlines and especially 12px/0.14em-tracked kickers will render spindly on Windows ClearType (low x-height, hairline strokes — a real screen-typography error), and Cormorant+gold-on-dark is currently the most common AI 'premium' shorthand, undercutting its anti-slop claim; the 2-column dispatch river also breaks strict chronological scan order on the one page whose whole job is 'what updated, in order', and a 340px lead band spends vertical space a reminder dashboard doesn't have. Modernity 6 reflects that a serif masthead reads 2023-editorial-site more than 2026 product. Final: GROUND STATION 50, MARQUEE 49, GAZETTEER 47 — the winner takes the stamp thunk, the Update All cascade, and the branch-compatibility check as grafts.
- winner: GROUND STATION — Judged as the engineer who has to ship this in days. GROUND STATION wins on specifics that survive CSS contact. - winner: GROUND STATION — Judged on specifics, not pitch prose. GROUND STATION wins on the two criteria this product lives or dies on: density and non-generic execution. Its concrete tokens hold up under scrutiny: cool-graphite ramp (#0A0C0E→#1D2328) with alpha-hairlines at 0.055/0.07/0.13 is a real Linear-grade system; the all-Plex superfamily (Sans/Condensed/Mono) is coherent, cheap (Google Fonts), CJK-safe, and the condensed-caps-labels-instead-of-boxes grouping device is a genuine designer move, not template behavior.
